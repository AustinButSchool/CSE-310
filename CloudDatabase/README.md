# Project Collection Maker

This is a website that uses Cloud Databases in order to store user information. This information is collections of media that they want to store from different websites. This lets them reffer to different things all in one website, and lets them share these collections with others.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Load the website at: 
2. Create an account with a Username and a Password. Right now, there is no account recovery, so make sure you will know it!

Instructions for using the software:

1. Create an account with a Username and a Password. Right now, there is no account recovery, so make sure you will know it!
2. To create a collection, create the + on the right of Saved Media. Choose what type of Media you are saving, and fill in the boxes. Hit saved item.
3. Go to your group, double click the media, and it will open a album of everything in the group. You have made a collection!
4. You can publish this group to be public for anyone to see. change the visability to Public, hit save, and it will now be public.
5. Go to Explore to see the Public groups. You can click on names to see peoples profiles. 
6. Go to User Settings to change your User Settings, such as username, description, and a spot to save a link to a profile photo.
