# Hello World

This is a program that does an animatied version of the Hello World! sentence.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Make sure you have Python downloaded, and load it into your IDE of choice, or your terminal.
2. Run the code!

Instructions for using the software:

1. Run the code when you have it loaded.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* You need any Python version after Version 3.0.
